# Official Brand Color Palette & UI Rules

Every UI implementation in this project must strictly utilize the five official brand colors:
- Peach Glow: `#FFC09F`
- Light Gold: `#FFEE93`
- Lemon Chiffon: `#FCF5C7`
- Light Blue: `#A0CED9`
- Celadon: `#ADF7B6`

Do not introduce competing brand colors. Use CSS tokens defined in `styles.css`. Maintain the clean photographic hero aesthetic without cards or floating panels.
